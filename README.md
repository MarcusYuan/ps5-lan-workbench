# PS5 Local Host

[简体中文](README.md) | [English](README.en.md)

在电脑上提供本地注入网页、管理插件和安装有权使用的本地游戏文件。支持单网卡连接同一路由器，或用另一块有线网卡直连 PS5。

**[下载最新版本](https://github.com/MarcusYuan/ps5-lan-workbench/releases/latest)** · [详细使用指南](guides/usage.zh-CN.md) · [联系与反馈](#联系方式与交流)

> 本项目用于技术交流和合法授权测试，不附带网页资源、第三方 ELF 或游戏内容。PS5 实机兼容性仍待验证；发送完成不代表内容已在 PS5 上成功运行。

## 下载并打开

在下载页面展开 **Assets**，根据电脑选择文件：

| 你的电脑 | 下载文件名包含 | 打开方式 |
| --- | --- | --- |
| Windows 64 位 | `windows-x64-setup.exe` | 安装后打开 |
| Windows 64 位，想直接运行 | `windows-x64-portable.exe` | 直接打开 |
| Mac，Apple 芯片（M 系列） | `macos-arm64.dmg` | 打开 DMG，将应用拖入“应用程序” |
| Mac，Intel 芯片 | `macos-x64.dmg` | 打开 DMG，将应用拖入“应用程序” |

macOS 也提供 ZIP。**Source code 是源码，请选择上表中的应用包。** 当前应用未签名，macOS 未公证，系统可能阻止打开。

## 连接与 IP 配置

在“连接模式与电脑 IP 配置”中选择：

| 模式 | 连接方式 | 选择哪块网卡 |
| --- | --- | --- |
| 单网卡 | 电脑与 PS5 连接同一路由器，可以都使用 Wi-Fi | 电脑当前正常联网的网卡 |
| 双网卡 | 一块网卡上网，另一块用网线直连 PS5 | 直连 PS5 的网卡 |

点击 **自动配置 IP**，默认额外添加服务地址 `192.168.100.1/24`，保留原 IP、DHCP、网关和 DNS。若提示地址或网段冲突，可换一个末位为 `.1` 的私有地址，PS5 按界面显示的同网段参数填写。Windows 和 macOS 支持自动配置，操作时可能需要系统授权。

在 PS5 手动填写 IP `192.168.100.2`、掩码 `255.255.255.0`、主 DNS `192.168.100.1`、网关 `192.168.100.1`，并在软件中保存相同的 PS5 地址。这套设置用于本地访问，不开启电脑网络共享或桥接；路由器需要允许设备互访。PS5 无需连接互联网。

停止本地服务与传输后，可点击 **清除本工具配置** 移除工具新增的地址；原本已有的地址不会被清除。退出软件会保留临时地址，重启电脑后地址失效，需要重新配置。[配置、恢复与限制](guides/usage.zh-CN.md#自动配置-ip-与清除)

电脑首次下载软件、网页和插件需要网络，缓存资源与本地文件可通过局域网使用；第三方资源可能有自己的外网依赖。自动配置已在一台 Windows 电脑上完成有线与 Wi-Fi 的真实添加、清除和原联网配置保留验证；macOS 实机及 PS5 连通性仍待验证。

## 从准备到游玩的七个步骤

下图展示双网卡直连方式；单网卡模式按上面的同路由器设置操作。

![电脑直连 PS5 的网络配置与七步使用流程](guides/assets/direct-connect-flow.zh-CN.png)

| 步骤 | 怎么做 | 为什么 |
| --- | --- | --- |
| 1. 下载并打开软件 | 从上面的下载入口取得应用。Windows 下右键应用，选择“以管理员身份运行”；macOS 按启动服务时的系统提示授权。 | 本地 DNS 和网页服务需要使用相应端口及系统权限。 |
| 2. 配置网络并关闭自动更新 | 选择连接模式和网卡，点击“自动配置 IP”，按提示手动填写 PS5 参数并保存地址；在 PS5 设置中关闭系统软件自动下载与自动安装。 | 固定地址让两台设备直接通信；关闭自动更新，避免固件自动变化影响所选资源的兼容性。 |
| 3. 下载网页仓库并启动服务 | “文件来源”默认预填 [Relapse 仓库](https://github.com/ntfargo/Relapse-Exploit)，入口为 `index.html`。确认与你的固件兼容后，点击“下载并检查” → “启动本地服务”；也可改为其他有权使用的仓库地址或 HTTPS ZIP 直链。已保存的来源会继续保留。 | 预填地址省去查找与复制；下载后由电脑向 PS5 提供本地网页和 DNS 服务。 |
| 4. 在 PS5 打开用户指南进行注入 | 进入“设置 → 指南与提示、健康与安全以及其他信息 → 用户指南”，按所选网页的说明操作，并在 PS5 确认注入结果。菜单名称可能随系统语言或版本变化。 | 主 DNS 将用户指南相关域名指向电脑，由 PS5 加载本地网页；注入能力及固件兼容性由所选仓库决定。 |
| 5. 在电脑管理并推送插件 | 确认 PS5 上的 ELF Loader 已允许电脑连接。在“安装插件”中按需下载，再点击“加载到 PS5”，到主机确认启动。已缓存插件可再次发送。 | 注入后的接收服务负责接收插件；后续安装游戏需要相应的管理服务先运行。 |
| 6. 选择本地游戏文件并安装 | 先在 PS5 启动 PKG Manager。在“安装本地 PKG”中选择或拖入你有权使用的 `.pkg`，点击“安装到 PS5”，保持电脑与文件可用直至安装反馈返回。 | PS5 从电脑读取安装文件，由 PKG Manager 处理安装，无需在主机下载游戏。 |
| 7. 确认结果并开始游玩 | 在 PS5 检查安装结果，尝试启动游戏；确认所需插件已运行且内容与固件兼容。 | 发送完成、安装成功与实际启动是不同状态，以主机上的结果为准。 |

插件包括 WebKit Autoloader、PKG Manager、Payload Manager、Kstuff、ShadowMountPlus、FTP Server 和 Web File Manager，按需选择。[插件说明与前提条件](guides/usage.zh-CN.md#组件与本地-pkg)

如果使用的是完整游戏目录或 `.exfat` / `.ffpkg` 镜像，第 6 步改用“发送游戏目录 / 镜像”：

1. 在 PS5 启动支持匿名登录的 FTP Server，默认端口 `2121`，发送文件到 `/data/homebrew/`；已有同名目标会被拒绝。
2. 先在 PS5 完全关闭游戏。在“安装插件”选择 **ShadowMountPlus 1.7beta2（默认）**或 **1.7beta3（可选预发布）**，点击“下载” → “加载到 PS5”，到主机确认启动。它需要与固件匹配的 Kstuff 运行环境；当前 Kstuff FPKG 测试版组合未经实机验证。两个版本独立缓存，可选择 beta2 再次加载；beta3 未确认能解决启动黑屏。
3. 在 PS5 检查 ShadowMountPlus 的扫描和游戏注册通知，再尝试启动。已上传的 `PPSA22999.exfat` 无需仅为加载插件重新上传。

镜像通过加载器扫描、注册和挂载，`.pkg` 则通过 PKG Manager 安装。[ShadowMountPlus 使用与排查](guides/usage.zh-CN.md#shadowmountplus-镜像加载) · [目录与镜像传输说明](guides/usage.zh-CN.md#游戏目录与镜像的-ftp-发送)

## 以后从 PS5 的 YouTube 启动

首次通过其他入口完成破解后，准备符合上游要求的 YouTube 应用、账号与更新阻止设置，并开启 FTP。在“安装插件 → 入口与插件管理 → Y2JB Autoloader”选择版本和已安装的 YouTube 应用 ID，下载后完全关闭 YouTube，确认准备完成，再点击“通过 FTP 安装”。软件会校验上传文件并备份原下载数据。

以后重启 PS5，打开 YouTube 执行破解流程和配置好的自动加载插件，日常启动无需打开电脑端软件；这不是永久破解。没有 `autoload.txt` 时会启动 Payload Manager，需先配置你要自动加载的插件。最新 Relapse 版本为预发布，实机兼容性待验证。[安装前提、版本与恢复说明](guides/usage.zh-CN.md#y2jb-autoloader-安装)

## 遇到问题

| 问题 | 先检查 |
| --- | --- |
| 不知道填哪个 IP | 选择连接模式和网卡，默认新增电脑服务 IP `192.168.100.1`，应用中的 PS5 地址填 `192.168.100.2`；如修改了网段，按界面提示同步填写。 |
| 下载失败 | 使用仓库地址或 ZIP 直链；GitHub 下载慢时可尝试“GitHub 镜像加速”，失败则关闭重试。该选项使用第三方服务。 |
| 本地服务无法启动 | 查看应用提示，检查系统权限及端口占用。 |
| PS5 打不开网页 | 检查直连网线，或同一路由器是否允许设备互访；核对两端 IP、掩码，以及 PS5 主 DNS 是否指向电脑服务 IP，确认本地服务已启动。 |
| 组件、PKG 或 FTP 连接失败 | 确认 PS5 地址正确，对应 Loader、PKG Manager 或 FTP Server 已在主机上启动。 |
| 显示“结果未确认” | 到 PS5 查看实际结果，避免立即重复操作。 |

进一步排查请看[详细指南](guides/usage.zh-CN.md)。开发者请看[源码运行与构建](guides/usage.zh-CN.md#从源码运行)及[发布规则](rules/github-release.md)。
