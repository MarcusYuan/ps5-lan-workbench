准备网页资源，启动本地 DNS/HTTPS 服务，再从 PS5 用户指南访问。

连接步骤
  1. 在电脑上下载网页资源并启动本地服务。
  2. 在 PS5 网络设置中将主 DNS 设为上方电脑 IP。
  3. 从 PS5 用户指南打开页面；证书提示需由用户自行确认。

在部分固件上，WebKit Autoloader 默认只接受 PS5 本机 ELF 连接。电脑发送插件前，请通过 Payload Manager 启用网络版 ELF Loader。
